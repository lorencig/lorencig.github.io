Naming convention

Full title, consistent, and easy to scan.

01

Keep the full title

Renaminator uses every title word, joined without spaces (CamelCase), and uses underscores consistently, with no unsafe filename symbols.

02

Resolve duplicates

Different papers with the same first author and year receive a, b, and subsequent letter suffixes.

03

Mark supplements

Supplementary files use the same base name followed by _SI. Use EndNote groups and keywords—not filenames—to classify papers by topic.
